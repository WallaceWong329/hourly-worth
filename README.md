# 🧮 打工計算機 Hourly Worth

你知道自己個鐘值幾多錢嗎？

輸入人工同返放時間，計下你返幾耐先買到你想買嘅嘢。

**[Live Demo](https://wallacewong329.github.io/hourly-worth/)**

## 功能

- 💰 月薪制 / 時薪制 切換
- ⏰ 每日輸入返放時間（支持長短週）
- 🔄 自動扣除休息時間
- 📊 即時計算：時薪、日薪、周薪、月薪、年薪
- 🛒 買嘢計算器：輸入價錢即刻計出要返幾耐工先買到
- 📅 長短週：每月自訂長短週數量
- 💾 所有資料自動儲存喺瀏覽器本地（localStorage）
- 📱 響應式設計，手機電腦都用到

## 使用方法

直接開 `index.html` 或訪問 [GitHub Pages](https://wallacewong329.github.io/hourly-worth/)

## 技術

- HTML (single file)
- [Vue 3](https://vuejs.org/) (CDN)
- [Tailwind CSS](https://tailwindcss.com/) (CDN)
